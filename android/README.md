# ASMR Player Android

在「设置 → 在线来源 → 选择站点」中可直接选择本站（api.asmr.one）、镜像 100、镜像 200（默认）或镜像 300，与 PC 的镜像预设一致。选择后立即保存；「编辑地址」仍可填写自定义 HTTPS 来源。站点访问凭据继续按来源分别保存。

「耳机音效偏好」先显示生效的方案与输出设备，再列出保存的方案和设备关联。暂停时显示最近确认的输出；还没有路由信息时，播放后再确认。「下载存储与缓存」分别显示离线下载和媒体缓存的实际占用。清理封面只针对浏览封面与已缓存主封面，不删除音频或下载的图片附件。

字幕设置分别显示当前音轨的原文、译文和读取状态。一份字幕无法读取时，另一份可继续显示；点出错卡片里的重试可重新读取该文件。「时间对齐」管理整体与译文额外偏移。下载管理先按作品展示进度，点开作品可操作文件。音效页顶端可以展开切换预设；「精细调整」可直接进入声道、参数均衡器和 AutoEQ。跨设备同步加入的在线作品缺少本地封面时，应用按当前在线来源的作品 ID 获取并缓存主封面。

详情页使用 4:3 大封面。标题、社团和 RJ 号从上到下排列，标题超过三行时点开全文弹窗，点击 RJ 号可以复制。音轨列表显示“听到”的时间或“已听完”。进入作品默认选中最近未听完音轨所在分组。“播放全部”续播当前分组内最近未听完的音轨，“从头播放”从该组第一轨的 0:00 开始。点单轨续播该轨，其他音轨的进度独立保存。

## 页面与控件动效（2026-11-11）

首页进入作品详情时保留同一个迷你播放器，导航下移退场，播放器连续下移；返回按原路径恢复，猫耳与进度填充保持连续。横向布局收起导航时，播放器连续扩展宽度。页面进入和返回使用 280 ms 双向位移与淡入淡出，离场页面保留画面但不接收点击和无障碍焦点；封面通过稳定作品 ID 执行 300 ms 共享位置、尺寸与圆角过渡。在线详情先使用发现卡已有的作品信息展示封面，再补齐网络音轨。

胶囊、展开项、抽屉内容变化与居中弹窗采用一致的缓动节奏；弹窗退出交给窗口动画，不延迟保存、播放或其他业务操作。系统关闭动画或启用低效果时，页面、共享封面、胶囊和内容展开直接显示目标状态。Compose BOM 同步到 2026.05.01（核心 1.11.2），避免旧版共享过渡在异步状态通知中的线程观察异常，并使用其快速反向过渡修复。

## 当前界面：直接操作与统一页面（AN007.R14）

作品卡片与详情使用 4:3 封面，保留编号、CV、标签、来源和收听状态。搜索图标与提示在同一行；详情先展示通栏完整封面，再显示作品信息、播放操作和音轨/介绍/附件。详情保留迷你播放器，四项玻璃导航仍位于主页面。

完整播放器采用已确认的海报裁切布局：封面左右贴边，主体按 AN007.R20.C 下移，上沿模糊过渡从 56dp 标题栏下方 8dp 开始；顶部保留收起按钮与居中的“播放”。封面使用完全对齐的清晰原图与柔化副本叠合，合成后按平滑曲线统一渐隐，减轻上下边界与重影；顶部渐入、中下部长范围渐隐，左右没有暗角或横向遮罩。收起箭头没有常驻圆底。背景参考 PC 沉浸页，封面中心铺满全屏并放大 1.16 倍、柔和模糊、饱和度 1.7、亮度 0.56、完全不透明；台词模式沿用同一背景。仅在封面变化时后台生成最长边 192px 的静态背景图与 384px 的柔化副本，不按进度更新；低效果模式关闭模糊副本、沿用封面色底与纵向渐变。点击封面或台词摘录打开居中台词，点句跳转、滑动浏览、点空白返回。纯台词模式隐藏标题与收藏/喜欢行，播放控制位置保持一致。无台词时只显示“暂无台词”，不提供点击导入；封面和台词摘录取消点击涟漪。底栏首项“收藏”使用书签形音频库图标，点击真实入库、成功后实心显示；标题旁只保留放大至 32dp 的音轨爱心。书签添加与查看在“更多 → 播放工具”中；标题点击行内展开；底部“分组”使用方框加号，打开将当前音轨加入保存分组的抽屉。播放页不显示前后 5 秒和 A–B 快捷按钮。标题优先使用资料库对应版本的音轨名称，无独立名称时保留来源原文。恢复暂停会话时优先展示同版本保存的总时长，仍由播放器真实 seekable 状态决定拖动可用性；无已知时长显示“时长待读取”，不为填充显示自动加载或播放。

## 使用

- “打开音频”通过系统文件选择器选择一个或多个音频，组成当前运行队列；不扫描整个媒体库。
- “发现”支持在线浏览、搜索、排序和分页；打开作品后可保存到库、加入喜欢、按目录/格式播放或下载。“播放链接”继续接受 HTTPS 音频直链。
- 播放页可播放/暂停/停止、切歌和拖动进度；后台服务提供通知、锁屏和耳机控制，并处理音频焦点与耳机拔出。
- “系统媒体与灵动岛”提供通知状态与系统设置入口；隐藏标题与封面默认关闭，显示当前标题与作品封面。开启后系统媒体使用中性标题和应用图标；已有明确保存的选择继续保留。应用内通过仅本应用可调用的命令读取原始标题。
- “音效”提供旁路、预设、高通、去齿音、空气感、左右交换/平衡、立体声峰值限幅、最多 10 段 PEQ 和粘贴 AutoEQ 参数导入。音效和隐私设置自动保存。

## 音频边界

当前固定 Media3 1.8.0 的 PCM16 处理路径，算法内部使用浮点计算；禁用 offload，并由 AudioSink 包装层拒绝压缩直通，避免绕过 DSP。只接受单/双声道 PCM。原声旁路保持处理器输入的 PCM16 样本，不能据此宣称高位深原样输出或系统/蓝牙全链路 bit-perfect。

处理器使用固定大小工作缓冲，保留约 4ms 的前瞻和 EOF 尾帧；seek/切歌清空旧状态。音效参数以不可变快照交给播放线程，切换音效不重启播放器。超过 Nyquist 的频段跳过，不偷偷移动其频率。滤波正增益预留净空，限幅双声道联动，不使用自动增益补偿。
