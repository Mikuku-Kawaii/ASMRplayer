# ASMR Player 1.3.0

本次更新加入本地语音识别、字幕翻译与字幕任务管理，并改善作品库、下载与桌面窗口体验。

## 新增与改进

- 支持 SenseVoice、Whisper、Faster-Whisper 和日语专用 Kotoba-Whisper，本地模型与运行库按需下载。
- 支持本机 Ollama 与 DeepSeek API 字幕翻译，提供全文翻译、词库和 Prompt 设置。
- 支持手动、目录批量及播放时自动识别与翻译，可查看任务进度、取消、重试和删除生成结果。
- 支持字幕编辑、时间同步与台本对齐，识别和翻译结果同步用于播放页、桌面歌词与灵动岛。
- 改善作品库查询、下载附件与已完成任务清理、页面状态恢复及窗口交互。

## 使用说明

识别模型和运行库默认不下载，请在设置中按需安装并选择。Ollama 使用本机模型；DeepSeek 会发送字幕文本并按 API 使用量计费。识别质量与速度依音源、模型及硬件而异，后续将继续优化识别和翻译，并计划重构 UI。

## 下载

- `ASMR.Player_1.3.0_x64-setup.exe`：Windows x64 安装程序。
- `ASMR.Player_1.3.0_x64_en-US.msi`：Windows x64 MSI 安装包。
- `latest.json`：软件自动更新使用的签名清单，无需手动下载。
