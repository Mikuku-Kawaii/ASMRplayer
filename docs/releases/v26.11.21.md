# ASMR Player 26.11.21

本次更新包含 Windows 与 Android 双端安装包，并合并原 26.11.20 的更新内容。

- **推荐作品**：在 Windows「在线浏览」或 Android「发现」中，选择「推荐作品」查看站点推荐；支持搜索、筛选和翻页，按站点给出的顺序展示。访客可以直接浏览，加载失败时可重试。
- **asmr.one 账号**：两端均可登录或退出当前来源的官网账号，查看该账号的个人推荐；推荐页也可直接进入账号设置。
- **Windows 交互**：优化文字右键菜单的操作与显示。

Windows 与 Android 分别检查各自的更新。26.11.11 及更早版本会先更新到 26.11.12，再检查各平台的新版本。
