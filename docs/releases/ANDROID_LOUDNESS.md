# Android 响度均衡

AN017，2026-11-02。入口：右上角三横 → 设置 → 音效与均衡器。保持既有页面与导航布局。

## 两个独立开关

| 功能 | 行为 | 适用来源 |
| --- | --- | --- |
| 实时响度均衡 | 根据约 400 ms 的 K 加权能量平缓调整增益，减小一轨内的音量起伏；保留部分动态，双声道使用相同增益 | 现有播放链支持的本地、已下载和在线音轨 |
| 音轨响度统一 | 完整解码测量一条音轨后，应用固定的目标响度差；在音轨内不跟随内容改变补偿 | 本地和已下载音轨；在线流提示先下载 |

默认均关闭。目标响度默认 −23 LUFS，可设 −30 至 −16 LUFS；最大提升默认 +6 dB，可设 0 至 +12 dB。默认值属于本播放器的保守初值，不代表所有 ASMR 内容都应达到广播目标。最大提升限制可能使极安静音轨无法达到目标。

原声旁路跳过两种处理，保留参数。均衡开启时现有双声道峰值限幅自动参与；仍可调整限幅上限。所有修改经现有服务即时应用，不重建播放队列或改变进度。参数随耳机方案保存，旧方案中缺少新字段时按关闭迁移。

## 分析、缓存与取消

- 音轨响度统一开启后自动分析当前本地/下载版本；缓存命中后直接复用。首次分析期间补偿为 0 dB，完成后平缓过渡到目标增益。
- 页面显示整轨分析进度、测量值和音轨补偿，提供取消、重新分析。切换版本、关闭统一或开启旁路会取消自动分析；旧任务结果不能用于新版本。
- 以稳定版本 ID 和来源 URI、大小、修改时间校验缓存；本地导入来源的变化由重新扫描更新，也可主动重新分析。文件结果仅保存在应用缓存目录，系统清理后重新分析；不修改音频或媒体标签，不纳入资料备份。
- 分析使用 MediaExtractor / MediaCodec 分块解码，不播放扫描声音、不读取完整 PCM 到内存。系统解码器不支持或授权失效时显示重试说明，继续保持原始补偿。
- 在线流不为分析额外下载整条音频；下载完成后可重新分析。实时均衡无需预扫描。

## 测量与信号链

综合响度采用单/双声道 K 加权、400 ms 测量块、100 ms 步进、−70 LUFS 绝对门限与 −10 LU 相对门限；用 0.01 LU 分桶的有界统计保持长音轨内存有界。参考 [EBU Tech 3341](https://tech.ebu.ch/docs/tech/tech3341.pdf) 与 [EBU R128](https://tech.ebu.ch/publications/r128)。未宣称通过完整 EBU 测量仪认证。

实时均衡在原始 PCM 上检测响度，使用部分目标差修正、约 80 ms 下压和 1.5 s 回升；低于 −50 LUFS 不追加动态提升。检测权重不用于修改可听频响。正增益会连同原有底噪一起放大，不能作为降噪功能。

实际链路：解码 → 既有前置增益/净空与 EQ/声道处理 → 音轨补偿和联动实时增益 → 既有 4 ms 前瞻限幅 → PCM16 输出。切换配置沿用短交叉淡变。原声算法旁路仍不等于 Android 系统、蓝牙或 DAC 端到端 bit-perfect。

当前峰值检测为 **sample peak**，没有增加过采样 true peak、LRA 或整张作品统一增益模式；不得将 dBFS 读数标为 dBTP。不同剪辑/格式版本分别测量，不自动合并。
