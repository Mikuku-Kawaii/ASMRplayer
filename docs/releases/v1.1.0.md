# ASMR Player 1.1.0

本次更新带来桌面灵动岛、GitHub 软件更新，以及设置、播放记录和下载可靠性修复。

## 桌面灵动岛

- 独立悬浮窗口与主窗口共用播放状态，点击胶囊展开播控，失去焦点后折叠；双击展开区域可唤回主窗口。
- 支持播放 / 暂停、切歌、滚轮调音和拖动进度；显示时间提示，并在拖动时预览字幕。
- 支持字幕上下文回看、切歌与音量瞬态通知、拖动磁吸、置顶、全屏避让和隐私模式。
- 设置中可调整置顶、磁吸、滚轮调音、通知时长和隐私模式。

## GitHub 软件更新

- 设置中检查正式版本、阅读更新内容，可开启启动自动检查，或选择稍后提醒、跳过此版本。
- 下载进度可见，支持取消与失败重试；签名验证通过后才可点击“安装并重启”。
- 安装前保存收听会话与数据库状态，保留用户记录和媒体文件。

## 可靠性修复

- 修复记录备份导入参数错误、设置保存时旧值覆盖与离页丢失，以及独占音频开关的并发写入。
- 修复音轨结束后“已听完”状态被覆盖、从零下载的 206 响应追加残留文件的问题。
- 数据库升级前备份包含 WAL 中未写回主文件的记录。

## 下载与升级

- `ASMR.Player_1.1.0_x64-setup.exe`：常规 Windows x64 安装程序。
- `ASMR.Player_1.1.0_x64_en-US.msi`：Windows x64 MSI 安装包。
- `latest.json`：软件更新元数据，无需手动下载。

1.0.0 没有内置更新器，需要手动安装 1.1.0 一次。后续更高版本可从软件设置中获取。当前开发中的屏幕选择、三档尺寸和灵动岛布局调整属于 1.1.1；自动更新的实际下载、安装与重启验收将在 1.1.1 发布时进行。
