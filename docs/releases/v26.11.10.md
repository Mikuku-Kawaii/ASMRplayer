## Android 端正式发布

ASMR Player 首个 Android 正式版现已开放下载，支持 Android 6.0 及以上。手机可直接安装本页的 [通用 APK](https://github.com/Mikuku-Kawaii/ASMRplayer/releases/download/v26.11.10/ASMR.Player_26.11.10_261110_universal.apk)。

> **在线来源提示**　近期上游网站服务异常，热门榜单、搜索和部分在线作品可能暂时无法加载，请耐心等待上游修复。已导入的本地音频可正常播放。

### Android 端功能

- **音频库与歌单**　从手机文件夹导入作品，也可以在线浏览和下载。音频库和喜欢页用网格卡片展示作品，还可以单独收藏音轨、建立歌单、为片段添加时间标记。
- **后台播放**　锁屏或切换应用后可继续收听，通过通知、锁屏控件或桌面小组件控制播放。首页猫耳开关可切换内容显示，点击时保持原位。
- **双语字幕**　播放页分别显示原文和译文。点封面可展开台本，手动翻阅后点「回到当前句」恢复跟随，也可在字幕时间轴点句跳转。
- **耳机与助眠**　可为耳机保存音效方案，调整均衡器，并设置睡眠定时。
- **跨设备同步**　在手机和电脑绑定同一种存储服务，即可同步音频库、喜欢的作品、收藏音轨、歌单、进度和时间标记。支持 GitHub Gist、OneDrive、WebDAV 和 Supabase。

### PC 端改进

- **歌单管理**　可从音频库挑选音轨加入歌单，也可右键作品，把优先音轨加入歌单。
- **沉浸播放**　新增左右声道翻转和可调时长的淡入淡出。切歌时先淡出上一轨，再淡入下一轨，暂停和恢复也支持平滑过渡。
- **桌面灵动岛**　可直接拖动进度条跳到想听的位置。
- **跨设备续听**　电脑端可绑定与 Android 相同的存储服务，在两端接续收听进度。

Windows x64 用户可下载 [EXE 安装包](https://github.com/Mikuku-Kawaii/ASMRplayer/releases/download/v26.11.10/ASMR.Player_26.11.10_x64-setup.exe) 或 [MSI 安装包](https://github.com/Mikuku-Kawaii/ASMRplayer/releases/download/v26.11.10/ASMR.Player_26.11.10_x64_en-US.msi)。
