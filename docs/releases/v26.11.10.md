## ASMR Player 26.11.10

Windows 与 Android 现提供同一版本的安装包。电脑请选择 Windows x64 EXE 或 MSI，手机请选择 Android 通用 APK。

- **跨设备收听**：两端支持 GitHub Gist、OneDrive、WebDAV 和 Supabase。音频库、喜欢的作品、收藏音轨、歌单、进度和时间标记可同步，音频文件仍由各设备管理。
- **Android 播放与字幕**：可后台播放，支持锁屏控制、耳机音效方案和睡眠定时。播放页分别显示原文和译文，展开台本可手动浏览并恢复跟随，字幕时间轴支持点句跳转。
- **Android 首页**：作品以网格卡片展示，迷你播放器与全宽导航分开排列。猫耳开关支持切换内容显示，切换时保持原位。
- **Windows**：新增歌单与沉浸播放设置，并更新灵动岛、字幕工具、外观和同步设置。两端换用猫耳耳机图标。
