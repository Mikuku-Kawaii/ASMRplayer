# ASMR Player 1.2.2

本次更新改善作品库整理、字幕显示与桌面窗口交互，修复目录移除后的索引残留问题。

## 新增与改进

- 导入、编辑元数据和关联作品使用统一弹窗，改善窄窗口布局、下拉菜单和键盘操作。
- 输入框支持统一的剪切、复制、粘贴右键菜单，调整按钮图文对齐、设置表单和操作反馈。
- 批量整理支持将选中作品追加到播放队列，保留当前收听状态与原有队列顺序。
- 作品列表与详情补充 R18、含字幕标识；可手动设置作品年龄分级，在线元数据同步保留用户设置。

## 修复

- 移除作品库目录引用时清理相关来源索引，防止旧目录监听重新导入；保留原始媒体、收藏、书签和收听记录。
- 改善灵动岛窗口初始化、布局同步与字幕切换，调整桌面歌词锁定、右键菜单及沉浸字幕居中跟随。
- 恢复会话时展示上次保存的音频信息，避免为恢复信息而加载音频或探测离线磁盘；实际播放前仍校验来源。

## 下载与升级

- `ASMR.Player_1.2.2_x64-setup.exe`：Windows x64 安装程序。
- `ASMR.Player_1.2.2_x64_en-US.msi`：Windows x64 MSI 安装包。
- `latest.json`：软件自动更新使用的签名清单，无需手动下载。

安装仅在用户明确点击后触发。独立环境的完整升级、四小时实机播放及部分高 DPI / 多屏验收仍保留在开发计划中。本版本不包含尚未实现的本地语音识别与翻译。
