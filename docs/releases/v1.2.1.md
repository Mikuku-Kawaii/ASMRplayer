# ASMR Player 1.2.1

本次更新新增独立桌面歌词，改善收听状态、收藏与播放界面的使用体验。

## 新增与改进

- 新增独立桌面歌词窗口，提供播放栏开关、外观设置及字幕跟随显示。
- 增加音轨版本收藏，完善播放栏中的作品收藏与喜欢操作。
- 分开记录当前播放进度与曾经听完的状态，重新收听时保留完成历史。
- 调整作品详情、批量整理和智能集合的状态展示与交互。
- 改善灵动岛文字滚动、窗口状态及设置体验。

## 修复与补充

- 修复从 1.2.0 升级后，带播放会话启动时可能出现的窗口卡住问题。
- 修复标题栏双击最大化、还原与窗口按钮状态同步问题。
- 新增 50% 至 150% 界面缩放设置，并保存所选比例。

## 下载

- `ASMR.Player_1.2.1_x64-setup.exe`：Windows x64 安装程序。
- `ASMR.Player_1.2.1_x64_en-US.msi`：Windows x64 MSI 安装包。
- `latest.json`：软件自动更新使用的签名清单，无需手动下载。

可在设置中检查更新。实际自动安装与重启流程尚待独立环境验收。
