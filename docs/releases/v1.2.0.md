# ASMR Player 1.2.0

本次更新扩展作品整理、书签笔记和下载管理，并改善软件更新、备份与桌面灵动岛体验。

## 作品管理与播放

- 在线浏览支持声优、社团、标签的包含与排除筛选，并可组合关键词、字幕和排序条件。
- 保存常用筛选为智能集合，根据当前音频库动态展示匹配作品。
- 批量修改收藏、喜欢、标签和收听状态，支持影响预览、失败重试与撤销。
- 书签支持笔记、标签和跨作品检索，可导出及恢复，保留对应音轨版本。
- 保存命名播放队列，支持预览、重命名、追加及确认替换，并提示不可用音轨。
- 新增命令搜索和应用内快捷键自定义，提供冲突检查与恢复默认。

## 下载、备份与存储

- 下载任务支持优先级、1–6 个并发任务、共享总限速、跨午夜下载时段及恢复偏好。
- 查看缓存、未完成下载与离线文件占用，清理前先预览范围。
- 自动备份支持周期与保留份数；恢复前预览内容、确认范围并备份现有记录。
- 诊断包支持内容预览和脱敏导出，不自动上传，不包含媒体或完整数据库。

## 更新与界面体验

- 独立更新弹窗展示版本与 Markdown 更新说明，支持下载进度、取消、重试及明确确认安装。
- 设置页可查看当前版本说明和历史版本，缓存内容支持离线阅读，升级后提供一次提示。
- 灵动岛支持过长字幕和标题滚动，调整紧凑与展开布局，并改善首次显示形状。
- 同一发行版本重复启动时唤回已有窗口；开发调试环境使用独立数据。
- 长字幕列表采用窗口化渲染，减少大字幕文件的界面负担。

## 下载与升级

- `ASMR.Player_1.2.0_x64-setup.exe`：Windows x64 安装程序。
- `ASMR.Player_1.2.0_x64_en-US.msi`：Windows x64 MSI 安装包。
- `latest.json`：供应用更新器使用的签名更新清单，无需手动下载。

1.1.1 用户可在设置中检查更新；1.0.0 用户需手动安装新版。实际自动安装、重启、长时间播放及部分多屏场景仍需实机验收。
