# ASMR Player 1.0.0

ASMR Player 首次公开发布，提供 Windows x64 桌面版本。把本地作品、asmr.one 在线收听和离线下载放进同一套音频库与播放器，适合长音轨、双耳录音与睡前收听。

## 主要功能

- **本地 + 在线**：按作品导入本地文件夹，保留目录分组；在线搜索关键词、RJ 号、声优与标签，浏览榜单并筛选带字幕作品。
- **进度接着听**：自动保存作品的当前音轨与位置，启动后恢复为暂停；软件内下载完成的同一音轨可以沿用在线收听的进度和书签。
- **离线下载**：预览下载内容和保存位置，查看任务进度，暂停、继续或重试；服务器支持时可断点续传。
- **字幕与沉浸播放**：支持 SRT / VTT / LRC，自动匹配、手动绑定、偏移调整、字幕搜索与点击跳转，提供封面和大字台词播放页。
- **睡眠定时**：按分钟停止或在当前音轨结束后停止，支持淡出；书签与 A–B 循环方便回到喜欢的片段。
- **DSP / 参数 EQ**：低频截断、齿音频段衰减、空气感、峰值限制器、交互式参数 EQ，以及 AutoEQ 参数文本导入；提供内置预设、自定义预设和作品独立音效设置。
- **Windows 桌面集成**：原生 SMTC 媒体控制、隐私脱敏模式、系统托盘、字幕与播控悬浮窗、WASAPI 共享 / 独占输出。
- **音频库维护与备份**：目录增量扫描、根目录重新定位，以及收藏、进度、书签、循环和音效配置的 JSON 导入 / 导出。

## 安装

在本次 Release 的 Assets 中选择一种安装包：

| 文件 | 说明 |
| --- | --- |
| `ASMR Player_1.0.0_x64-setup.exe` | 常规 Windows x64 安装程序 |
| `ASMR Player_1.0.0_x64_en-US.msi` | Windows x64 MSI 安装包 |

安装包已包含 libmpv 播放动态库。界面需要 Microsoft Edge WebView2 Runtime；若系统缺少该运行时，安装程序会尝试联网下载。

附件中的 `SHA256SUMS.txt` 提供文件校验值，第三方声明说明随包分发的依赖及其许可。

安装后导入本地作品目录，或打开在线浏览页搜索作品，即可开始收听。完整说明见 [README](https://github.com/soradasuki162-star/ASMRplayer#readme)。

## 使用说明

- 在线功能依赖第三方服务和网络，可在设置中调整 API 与代理。本地音频可离线使用。
- 本地库扫描识别 MP3、FLAC、WAV、M4A、OGG、OPUS；建议字幕使用 UTF-8 编码。
- 独占输出取决于音频设备与驱动支持。DSP 预设和峰值限制器可按需调整，收听前请确认音量。
- JSON 备份保存收听记录与相关配置，不包含音频、封面或字幕原文件。跨机恢复时仍需准备相应媒体文件。
- 第三方动态库及其他依赖的许可说明见 [THIRD_PARTY_NOTICES.md](https://github.com/soradasuki162-star/ASMRplayer/blob/main/THIRD_PARTY_NOTICES.md)。
