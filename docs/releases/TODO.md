# ASMR Player 后续开发计划

## 后续发布 · GitHub 自动更新（P1）

- [ ] **T1401 GitHub Releases 版本检查**：基于 `Mikuku-Kawaii/ASMRplayer` 的正式 Release 检查新版本，支持启动时自动检查与设置页手动检查；正确比较版本号，默认跳过草稿和预发布版，允许关闭自动检查。
- [ ] **T1402 更新提示与发布说明**：显示当前版本、新版本和更新内容；提供“下载更新”“稍后提醒”“跳过此版本”，无更新或检查失败时给出明确状态。
- [ ] **T1403 更新包与签名校验**：接入 Tauri updater 的发布元数据、平台匹配和签名校验，GitHub Release 附带相应更新包与元数据；签名私钥和发布凭据保存在安全配置中，不提交到仓库。
- [ ] **T1404 下载、安装与重启**：展示下载进度和失败重试；在用户确认安装后保存播放位置与会话，再安全退出、安装并重启，避免收听过程中自动打断。
- [ ] **T1405 用户数据保护与回退**：升级保留音频库、收藏、进度、书签、音效配置和用户媒体；校验失败或网络不可用时保留当前可用版本，并提供 GitHub Releases 手动下载入口。
- [ ] **T1406 更新流程验收**：覆盖无更新、新版本、预发布过滤、版本比较、断网、下载失败、签名错误、取消/稍后安装、升级后记录恢复；自动更新完成前仍沿用手动下载安装包。


自动更新尚未实现，当前版本通过 GitHub Releases 手动下载。技术参考：[Tauri Updater](https://v2.tauri.app/plugin/updater/)。
