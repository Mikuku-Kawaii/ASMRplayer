# ASMR Player 1.1.1

本次更新优化桌面灵动岛的布局、动画和多屏适配，并修复启动初始化问题。

## 桌面灵动岛

- 设置中可选择显示屏幕，以及特小、小、中、大、特大五档尺寸，随分辨率与 Windows 缩放适配。
- 毛玻璃与胶囊共用圆角轮廓，使用轻弹性过渡；固定窗口画布与内部布局，减少展开、收回时的横向抖动。
- 紧凑态使用粗体大字幕，宽度随字幕调整；无字幕时显示标题。增加两侧留白，展开态仅显示单行音轨标题，并放大进度与播控。
- 调整裁剪后的重绘和动画结束尺寸；取消原生白色提示窗，将键盘焦点提示移至封面内部，避免外沿亮框。
- 通知停留时间改为带开关、数值和刻度的滑条。

## 其他改进

- 后端服务注册完成后再创建窗口，避免冷启动作品库请求出现 `state not managed`。
- 详情页 RJ 标签支持点击复制完整编号，并提供轻微动效反馈。
- 底部播放栏固定显示音轨、作品与来源信息，不再显示字幕。
- 新会话默认音量为 100%，已有音量设置保持不变。

## 安装包

- `ASMR.Player_1.1.1_x64-setup.exe`：Windows x64 安装程序。
- `ASMR.Player_1.1.1_x64_en-US.msi`：Windows x64 MSI 安装包。
- `latest.json`：供应用更新器使用的签名更新元数据。

本地打包不代表 GitHub 已发布；1.1.0 → 1.1.1 的实际自动更新流程仍待发布后在独立环境验收。
