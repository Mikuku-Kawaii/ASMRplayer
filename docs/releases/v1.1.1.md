# ASMR Player 1.1.1

相较 1.0.0，本次更新新增桌面灵动岛与 GitHub 软件更新，完善多屏布局和交互，并修复设置、播放、下载与启动问题。

## 桌面灵动岛

- 独立悬浮窗口与主窗口共用播放状态，点击胶囊展开播控，失去焦点后折叠；双击展开区域可唤回主窗口。
- 支持播放 / 暂停、切歌、滚轮调音和拖动进度；显示时间提示，并在拖动时预览字幕。
- 支持字幕上下文回看、切歌与音量瞬态通知、拖动磁吸、置顶、全屏避让和隐私模式。
- 设置中可调整置顶、磁吸、滚轮调音、通知时长和隐私模式。

- 设置中可选择显示屏幕，以及特小、小、中、大、特大五档尺寸，随分辨率与 Windows 缩放适配。
- 毛玻璃与胶囊共用圆角轮廓，使用轻弹性过渡；固定窗口画布与内部布局，减少展开、收回时的横向抖动。
- 紧凑态使用粗体大字幕，宽度随字幕调整；无字幕时显示标题。增加两侧留白，展开态仅显示单行音轨标题，并放大进度与播控。
- 调整裁剪后的重绘和动画结束尺寸；取消原生白色提示窗，将键盘焦点提示移至封面内部，避免外沿亮框。
- 通知停留时间改为带开关、数值和刻度的滑条。

## 其他改进

- 后端服务注册完成后再创建窗口，避免冷启动作品库请求出现 `state not managed`。
- 详情页 RJ 标签支持点击复制完整编号，并提供轻微动效反馈。
- 底部播放栏固定显示音轨、作品与来源信息，不再显示字幕。
- 新会话默认音量为 100%，已有音量设置保持不变。

## GitHub 软件更新

- 设置中检查正式版本、阅读更新内容，可开启启动自动检查，或选择稍后提醒、跳过此版本。
- 下载进度可见，支持取消与失败重试；签名验证通过后才可点击“安装并重启”。
- 安装前保存收听会话与数据库状态，保留用户记录和媒体文件。

## 可靠性修复

- 修复记录备份导入参数错误、设置保存时旧值覆盖与离页丢失，以及独占音频开关的并发写入。
- 修复音轨结束后“已听完”状态被覆盖、从零下载的 206 响应追加残留文件的问题。
- 数据库升级前备份包含 WAL 中未写回主文件的记录。

## 安装包

- `ASMR.Player_1.1.1_x64-setup.exe`：Windows x64 安装程序。
- `ASMR.Player_1.1.1_x64_en-US.msi`：Windows x64 MSI 安装包。
- `latest.json`：供应用更新器使用的签名更新元数据。

1.0.0 没有内置更新器，需要手动安装 1.1.1 一次；后续版本可在软件内更新。实际自动安装与重启流程尚待独立环境验收。
