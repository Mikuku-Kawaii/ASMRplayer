# 材质、几何与 Tab 动效

## 记录范围

2026-10-26 从 FluxManga 本地当前 Kotlin 源码提炼，区别于早期固定底栏或关闭采样的历史方案。本文是方法说明，不包含应用源码副本、账号、截图或运行数据。下面数值是当前实现起点，不是平台标准或性能结论。

## 坐标与图层

- `GlassBackdropHost` 的 content 记录页面，overlay 绘制玻璃；用会话身份作为 sourceKey，空间改变或采样关闭时重建 / 释放图层。
- 源页面记录与过滤层不同：过滤层只覆盖底栏采样带及边缘余量，不能因此宣称完全没有全页记录成本。
- 模糊半径 16dp；过滤余量为三倍模糊半径加材质 18dp 与折射 4dp。选中透镜另有 18dp 局部绘制余量。
- 用宿主到局部的实测坐标对齐源图。滚动内容变化和胶囊位置变化都要触发相关材质重绘；只有背景滚动时别重建稳定 shader。
- API 31–32 的当前实现对嵌套图层有直接记录内容的适配分支；这是项目管线兼容措施，移植时先确认目标 Compose 版本是否需要。
- 缓存 shader、路径及效果对象；RenderEffect 封装可能快照 uniform，几何 / 材质改变时重建相关封装，不能只改 uniform 却一直复用旧效果。

## 当前材质参数

| 参数 | 源码值 / 行为 |
| --- | --- |
| 背景采样、模糊、微染色、高光、折射、饱和度 | DockEffects 默认 true；低效果和减少动画默认 false |
| 额外轮廓融合开关 | 默认 false；空间转场期间可临时启用 |
| 饱和度 / 亮度 | 1.35 / 1.05 |
| 主材质折射边带 / 位移 | 14dp / 4dp，API 33+ |
| 选中透镜 | 折射位移为基础值 1.7 倍，放大参数 0.08 |
| API 31–32 选中透镜近似 | 背景重放缩放 1.06，配合宿主模糊；不是 UV 折射 |
| 微染色强度 | 0.025 |
| 选中外柔光 | 10dp 模糊、主题色 alpha 0.10，下移 2dp |
| 选中边缘 | 1.2dp 视觉宽度，通过双倍描边后裁去外半边实现 |
| 静态细颗粒 | 外层材质缓存 48 个位置，alpha 0.012；选中胶囊不叠加 |
| 静止融合 | fusionScale = 0，API 31–32 去除残余阈值模糊 |

API 33+ 的完整材质由 SDF 联合轮廓、法线与背景折射组成；API 31–32 融合使用模糊加 alpha 阈值。两条路径共享同一几何，融合只改变轮廓，不自动等于玻璃。

低效果关闭背景采样和光学增强，选中态改用实色与边线；减少动画主要影响运动，不必自动抹掉材质。实际调用方可以将低效果同时用于停止动态反馈。

## 几何与自适应

当前起点：水平浮动边距 22dp、功能舱间隙 12dp、主栏内容上下余量 4dp、单项最小高度 48dp、图标 20dp、图文间隔 6dp、标签 13sp / 16sp 行高。高度取最高内容槽加上下余量，不写死整栏高度。

宽度 W、项目数 N 时，使用整数边界 `edge[i] = floor(W * i / N)`；槽宽是相邻边界差。胶囊宽度取目标槽宽、左右位置在同一边界数组插值，最终放置取整。所有像素恰好分配一次，避免分别 round(W/N) 后首尾缝隙。

按最宽标签、图标与内边距估算横排所需宽度，不足时使用竖排。主栏和选中态半径均是实际高度 / 2；前景放置取整后，将同一个像素修正传给背景 SDF，避免边缘错位。

## 单弹簧与应变

| 属性 | 当前起点 |
| --- | --- |
| 胶囊位置弹簧 | dampingRatio 0.72，stiffness 380 |
| 满应变速度 | 每秒 7 个 Tab 宽度 |
| 横向最大拉伸 / 纵向最大压缩 | 0.22 / 0.06 |
| 按压缩放 | 0.92，弹簧 0.72 / 550 |
| 选中图标缩放 | 1.15，弹簧 0.72 / 380 |

`strain = clamp(abs(position.velocity) / 7, 0, 1)`，仅在弹簧运行时非零；图层缩放为 `(1 + 0.22 * strain) * pressScale` 与 `(1 - 0.06 * strain) * pressScale`。形变不参与测量。

当前实现让同一个 Animatable 的新 animateTo 中断前一个动画以延续速度，不先 snap 回旧 Tab。项目顺序改变时按稳定 key 列表重建运动状态，避免跨不相关项目滑动。减少动画直接 snap，形变归零。

## 源码定位与复用边界

来源项目相对路径均在 `app/src/main/java/com/flux/manga/` 下；AI_Skills 不附带这些文件，使用本文无需访问它们：

- `ui/glass/GlassBackdrop.kt`：采样、过滤及会话图层生命周期。
