# Taste — ASMR Player 适配入口

本入口为 2026-11-01 的项目适配；上游 references/assets/scripts 完整保留。根 AGENTS.md 与 [M3 规范](../asmr-player-m3-ui-standards/SKILL.md) 优先。

审查应用界面时读取 [App screens](references/app-screens.md)，提炼主任务优先、产品真实内容、导航退后、数字与未知值诚实、网格闭合和渐进展示。文中比例与样本统计是上游经验，不是本项目合格阈值；安静不能以隐藏音量、状态或必要文字为代价。

围绕封面、作品标题、继续收听、双语字幕和可预期的播放控制建立辨识度；保持系统字体与紫色 Token，不强制随机抽取方向或重新设计品牌。作品卡片是必要内容容器，不能因为上游反模板偏好移除全部卡片。

先读取代码与已有截图，提出局部方向、实际内容分配和可验证的方案；只有用户要求实施才修改 UI。沿用已有样式与组件，不复制 assets/app.css 替换整套主题。

本地不自动运行 draw、assets、inspect 或录制脚本，不自动下载素材或启动浏览器调试。需要渲染检查时使用当前允许的浏览器/原生工具；用户媒体不能上传。营销页流程只在用户实际要求宣传页面时按需参考，不用于设置和播放界面。

来源、版本、许可和适配范围见 [来源清单](../SOURCES.md)。
