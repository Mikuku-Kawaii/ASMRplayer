# 布局、无障碍与真实反馈

从 AI_Skills 的相关 UI 工作流提炼并改写为 Android 指导；来源与排除项见 [sources.md](sources.md)。项目约定和已确认设计优先，不依赖原项目的 Web 文件、组件或脚本。

## 主任务与信息收纳

先沿既有页面职责确定对象、主要动作和必要状态；原创性来自内容组织、留白与准确反馈，不要求新配色、巨型标题或把每个分区都做成卡片。

- 高频任务留在主区；对象管理用有名称的更多入口，局部偏好进已有面板，全局偏好与诊断进设置。收纳不删除能力，核心操作不只靠长按或悬停发现。
- 按组件实际可用宽度重排，区分页面边距、内容网格和行内前导 / 文字 / 操作槽，不用整页缩放或逐页位移修补共享布局。
- 按钮外观、主要 / 危险用途、尺寸、按下与持久选中分别判断；沿用同一组件，不按图标有无决定重要程度，不全局改成透明或全宽。
- 菜单项、值选择、输入表单各用现有合适原语；含输入的面板不伪装成纯命令菜单。材质和描边调整保留控件识别、焦点和真实操作。
- 源码检查可从排版、留白、层级、颜色、动效、微交互、响应式和产品识别八方面定位具体问题；不为凑齐维度添加交互，也不把源码推断写成已看到的效果。

## 从内容决定布局

先确定页面主要任务、主操作和低频操作去向，再实现布局。保留现有功能入口，诊断和长路径按需要放到详情或设置；不靠缩小字体把所有信息塞进首页。

- 按实际可用宽度、字体缩放、Insets 和 IME 安排内容，不能只检查固定屏宽预览。
- 动态行分别安排前导、可收缩文本和尾部操作；标题省略时保留触摸或无障碍可达的完整阅读入口。操作、加载图标和数字变化不应挤掉关闭、取消与恢复入口。
- 复验长中英文书名、无空格标识、9→10 / 99→100、未知总量、缺图、空列表、多结果及大字。封面成功与失败保持预定比例和占位；正文和图片按内容选择适配或裁切。
- 明确每层滚动责任，底部条目能滚出悬浮控件和键盘遮挡。弹层内部容纳长内容，关闭入口始终可达。
- 使用稳定列表键；查询、筛选、滚动与草稿由适当状态所有者保持。离开页面时按任务性质取消请求或交接后台任务，不让隐藏页面持续昂贵绘制。

## Android 无障碍与输入

使用 Compose 现有语义和控件，不机械移植 DOM、ARIA、Radix 或 CSS。为图标操作提供名称，装饰图标避免重复朗读；可访问名称包含可见标签，选择、展开、禁用和加载状态与实际行为一致。

- 点击热区与图形尺寸分开，按项目 Android 目标验收；默认交互目标至少 48dp，不套上游桌面 px 尺寸。
- 验证 TalkBack 顺序、状态播报、键盘焦点与触摸操作。弹层关闭后返回合理触发位置，系统返回逐层关闭；非模态层不冒用模态行为。
- 输入法组合期间不触发全局提交或快捷动作；返回、IME 收起和导航保持项目约定。必要操作不能仅靠长按、悬停或无说明手势发现。
- 行点击和尾部动作分别可达，避免嵌套点击让收藏、更多或选择误触整行导航。
- 对比度检查真实前景与合成背景，覆盖浅深、图片和低效果状态；文字、选择与错误不能只靠颜色表达。不要为贴近参考图裁字、隐藏焦点或降低必要可读性。

## 请求、错误与长任务

读取真实 API 和取消能力，按本次受影响场景区分首次加载、刷新、空、无匹配、离线、失败、部分成功与阻塞。刷新时在业务允许范围保留已有内容，失败保留输入和上下文；跨账号或空间不得借此展示旧身份内容。

- 进度来自真实阶段和可测总量；未知时显示阶段或不定进度，不造百分比。正在取消、已取消、下载完成、校验通过和安装完成各有不同含义。
- 骨架仅用于结构明确的首载，小操作可保留现有轻量进度；不强制所有请求使用骨架。可用内容刷新保持稳定，身份切换仍先清旧内容。
- 反馈说明实际原因与下一步：字段错误靠近字段，当前内容失败在原区域，后台事件可用通知并保留再次查看路径。无需把所有错误改为弹窗，也不预留整块错误空白。
- pending 阻止重复提交，保留实际可用的取消、详情和安全导航；只提供后端真实支持的操作，不显示无效重试按钮。
- 写入结果不明时先查询结果，再决定重试；页面重建或刷新不自动重放写操作。异步任务生命周期与界面动画分离。
- 字段错误靠近字段；内容失败使用原容器状态位；简短非阻断反馈、后台任务汇总和阻塞确认按语义选用，普通失败不一律弹窗。
- 长诊断可在详情中滚动和复制，脱敏后展示；不能为了整洁丢掉唯一错误原因。重复事件合并播报，关闭通知不表示任务成功或错误消失。

## 按当前授权检查

先执行主技能的范围与停止条件。项目暂停测试时只检查实现和源码，不新增测试任务；允许验证后复用现有入口，只检查受影响行为。布局、读屏、状态和性能证据分别说明，不能因本技能建立完整测试框架或自动续跑历史专项。

## 设置与可扩展内容的增量规则

配置区分初始读取、草稿、保存中和已确认值；首载失败不把默认值提交回去，切分类保留草稿，恢复默认沿既有保存协议。即时开关与保存型字段不因外观改造互换提交时机，结果未知先核对，秘密显隐不触发保存或日志。

说明区和控件区按内容分配空间；长文案、多动作或大字时上下重排，不让短按钮自动撑满。已有 Compose action / footer 槽为空时收回专属间距，新增槽按实际需要；吸附保存区不遮底部内容、校验或 IME。设置专项按需使用 ui-settings-design，文字与槽位专项用 ui-text-presentation，不套来源项目的固定桌面侧栏。
