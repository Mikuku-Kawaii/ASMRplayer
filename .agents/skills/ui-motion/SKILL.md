# ui-motion

动效只解释位置、层级或状态变化，不以结束事件触发保存、播放或取消。沿用现有样式和动画偏好，不强加新的动效依赖。
自动跟随字幕时优先保持行高与锚点稳定，避免字号变化和滚动叠加引起跳动。高亮可使用颜色与字重，是否改变大小以阅读目标和实测决定。
检查 prefers-reduced-motion，减少动态时信息完整且操作等价；离屏装饰停止，持续波动/跑马灯不让整个页面每帧重渲染。
验证快速切换、中断、回退和低性能环境；不要用 transition:all 或人为延时掩盖真实状态。
