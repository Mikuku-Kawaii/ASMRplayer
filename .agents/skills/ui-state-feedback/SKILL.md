# ui-state-feedback

读取真实 DTO、命令返回与任务事件，区分首载、刷新、未知总量、无内容、部分成功、取消中、失败与完成。已有内容在刷新时保留；不能把请求发出或动画结束当作成功。
字幕任务明确当前音轨、阶段和计数分母。待翻译、翻译失败、待音频核对、确认非台词与完成不得用一个空字符串表示；待核对不自动等于不能翻译。
同一错误提供简短摘要、可再次打开的详情和现有恢复入口；批量错误合并，避免多个通知重复播报。局部错误贴近字段且关联 aria-describedby。
动作 pending 保持尺寸、样式类别与草稿；仅支持的任务显示取消和局部重试。取消按钮不随整组忙碌被误禁用；未知写入结果先核对，不能盲目重发。
