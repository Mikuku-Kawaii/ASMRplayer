# ui-design-quality

按排版、留白、层级、颜色、动效、微交互、响应式和原创性检查；静态区域不适用的状态标 N/A，不能为凑齐增加动效。
优先判断能否找到作品、控制播放、理解字幕任务与保存设置。原创性来自作品封面和有用的交互细节，不来自每屏新配色或卡片装饰。
每项记录页面/控件、实际证据、用户影响、优先级、解决方案及验收方式。区分源码事实、旧截图、当前实机和推断，不虚构分数或获奖认证。
先解决高影响问题，再同条件复查；任务内已无具体缺陷即停止，不无限追求风格完美。
