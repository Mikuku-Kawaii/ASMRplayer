# ui-text-presentation

先区分对象标题、关键状态/值和辅助说明，再映射 M3 字阶。低层级不是低可读性；11px 与边线色不宜承载关键帮助。
组内标签与值邻近，相关数字注明单位、口径和范围；长中文/日文标题与双语字幕保留合理行高，不靠强制逐字断行或缩字挤入。
低频细节使用可聚焦帮助或详情，必读风险与失败摘要保持可见。遵守本项目禁止展示文字拖选的约定，完整内容需要复制时给显式操作。
共享容器优先使用已有 children 与具名槽位；新增状态或动作不改变阅读/焦点顺序，不为未使用的槽位预留大块空白。
