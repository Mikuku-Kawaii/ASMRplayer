# ui-workspace-layout

先读 src/app/App.tsx、目标页面与 src/styles.css。明确作品浏览、播放控制、设置、字幕阅读各自的主任务；不能把营销页 Hero 或巨幅留白搬进工具区。
以实际内容容器宽度分配导航、主区与辅助区，不能只看窗口宽度。窄窗先收纳低频辅助操作；保留当前分类、筛选、草稿、选中对象和返回滚动位置。
每一区域只指定一个纵向滚动所有者，检查 min-width:0/min-height:0、底部播放器占位、弹层裁剪和文字放大。原生拖拽热区不覆盖控件。
Rust 播放状态仍唯一权威；隐藏或切页不停止播放器。针对页面自己的无用订阅检查释放，不能把来源项目的“隐藏即停播放”照搬到本项目。
